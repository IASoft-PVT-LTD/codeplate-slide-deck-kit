# Project decisions

<!-- codeplate:project-stub -->

This file is still the template stub. The agent replaces it after interviewing the user (see "Interview" in AGENTS.md), then adds every later decision here, so a future session knows what was agreed.

Suggested layout once filled in:

- **Who and what:** the presenter or organisation, what the decks are for
- **Browser:** the browser path that works on this computer
- **Brand:** logo file (and a badge behind it, if any), colours (main, accent, the accent shade used for text and why), fonts and their licences
- **Decks:** one line each: file, purpose, audience, length, how it's delivered (live, PDF, PPTX)
- **Outlines:** where each agreed outline came from (the user's notes, a document); changes the user approved
- **Rules:** words per slide, speaker notes, 16:9 or 4:3 per deck
- **Exports:** who gets which file (PDF, handout and its paper, picture or editable PPTX)
- **Numbers and sources:** every chart's data and where it came from
- **Pictures:** where they came from (the user's own, CC0 with links)
- **Open questions:**
- **Log:** one dated line per notable change
